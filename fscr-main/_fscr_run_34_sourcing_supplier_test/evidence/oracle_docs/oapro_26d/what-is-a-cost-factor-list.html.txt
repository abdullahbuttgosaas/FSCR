 Previous Next JavaScript must be enabled to correctly display this content Implementing Procurement What is a cost factor list? What is a cost factor list? A cost factor list is a collection of cost factors that you can apply to a negotiation line. When you apply a cost factor list, all the cost factors on the list are associated with that line. You can delete any cost factors you don't need. Cost factor lists allow you to quickly associate a group of related or commonly used cost factors with a negotiation line. This speeds up the creation process.
