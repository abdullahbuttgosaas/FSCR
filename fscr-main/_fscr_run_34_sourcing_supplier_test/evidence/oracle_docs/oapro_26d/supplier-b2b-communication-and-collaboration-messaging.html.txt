 Previous Next JavaScript must be enabled to correctly display this content Implementing Procurement Supplier B2B Communication and Collaboration Messaging Supplier B2B Communication and Collaboration Messaging As a procurement administrator, you can configure Oracle Procurement Cloud to use Oracle Fusion Collaboration Messaging for electronic business to business (B2B) communication with your suppliers. With Collaboration Messaging you can set up B2B communication to work within the procure-to-pay business flow. You can perform the configuration using the Collaboration Messaging work area. Collaboration Messaging provides ready-to-use integration with Oracle Business Network and other predefined service providers. You can enable messages for inbound and outbound communication. You can also communicate attachments and the purchase order PDF with your outbound purchase order and change order messages.
