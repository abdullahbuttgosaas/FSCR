 Previous Next JavaScript must be enabled to correctly display this content Implementing Procurement Supplier Outbound Synchronization Service Supplier Outbound Synchronization Service When using Oracle Supplier Model as the master supplier data repository it's often necessary to send the supplier record updates to another application that depends on this supplier data. The Supplier Outbound Synchronization Service lets you perform real-time synchronization of updates in the supplier master to other applications. This is achieved by generating a snapshot of the supplier profile record whenever it is created or updated. The snapshot output is an XML file that models the supplier data structure. The XML file is then delivered securely over HTTPS to a target destination for use by a downstream application. For more information refer to the Supplier Outbound Synchronization Service white paper on My Oracle Support.
