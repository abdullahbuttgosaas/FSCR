 Previous Next JavaScript must be enabled to correctly display this content Implementing Common Features for SCM Functional Area Catalogs Functional Area Catalogs Functional areas represent products or functionality of the product. Each functional area can have a set of rules to define how a catalog should be configured to support the functional area. When a catalog is created and assigned to the functional area, it's validated against the functional area rules. For example, many of the Supply Chain Management applications participate in a new item process which automatically assigns an item being created to the default category in a functional catalog. Also, if no catalog is assigned to the functional area, the functional area is skipped in the automatic assignment process.
