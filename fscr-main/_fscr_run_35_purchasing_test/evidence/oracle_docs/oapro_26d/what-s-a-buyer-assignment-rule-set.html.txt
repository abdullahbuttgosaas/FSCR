You can use rule sets to manage large numbers of assignment rules. Rules that share a common use can be grouped under a name that you can later use to filter search results. To manage assignment rules, in the Setup and Maintenance work area, use the Manage Buyer Assignment Rule Sets Lookup task in the Purchasing Foundation functional area.
