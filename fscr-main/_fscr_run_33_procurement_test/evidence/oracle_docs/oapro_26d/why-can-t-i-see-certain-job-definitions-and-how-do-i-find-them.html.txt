Why can't I see certain job definitions, and how do I find them? In the table on the Manage Job Definitions tab, not all job definitions are shown. You always see only the ones you have access to, and only the first 100 are shown when you open the tab. Use Query by Example to find what you're looking for, even the job definitions that aren't shown in the table by default. Related Topics Use Query By Example
