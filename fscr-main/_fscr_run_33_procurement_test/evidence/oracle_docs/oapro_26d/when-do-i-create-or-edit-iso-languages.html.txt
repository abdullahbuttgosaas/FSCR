 Previous Next JavaScript must be enabled to correctly display this content Implementing Procurement When do I create or edit ISO languages? When do I create or edit ISO languages? Edit the names and descriptions of International Organization for Standardization (ISO) languages to determine how they appear in the application. The ISO languages are a part of the ISO 639 standard. If any change to the ISO standard doesn't reflect in the application, you can update the ISO alpha-2 code or add languages to provide up-to-date information.
