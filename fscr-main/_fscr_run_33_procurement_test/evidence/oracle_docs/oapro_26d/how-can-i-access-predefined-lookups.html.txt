Search for predefined lookups using any of the manage lookups tasks. In the Setup and Maintenance work area, go to any of the following tasks that contains the lookups you're looking for: Manage Standard Lookups Manage Common Lookups Manage Set-enabled Lookups Enter any of the search parameters and click Search . If you don't know the lookup type or the meaning, use the Module field to filter search results. Click a lookup type to view its lookup codes.
