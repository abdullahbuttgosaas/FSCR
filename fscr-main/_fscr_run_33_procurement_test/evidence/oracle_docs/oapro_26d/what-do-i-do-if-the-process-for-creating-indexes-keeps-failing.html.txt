What do I do if the process for creating indexes keeps failing? It might be because of one or more of these reasons. You entered incorrect index names while submitting the process. Make sure that your ESS job parameters have the correct index names. If the problem persists, contact your help desk. You might not have enabled the search extension framework. Make sure you enable it. Your search cloud service isn't reachable. To check its availability, submit the ESS process to check Search Cloud Service availability process.
