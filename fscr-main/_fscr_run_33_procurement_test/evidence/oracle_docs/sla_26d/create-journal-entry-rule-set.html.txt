 Previous Next JavaScript must be enabled to correctly display this content Implementing Subledger Accounting Create a Journal Entry Rule Set Create a Journal Entry Rule Set In this procedure, you create a journal entry rule set. Navigate to the Manage Journal Entry Rule Set page. From the Setup and Maintenance work area, click the Implementation Projects button. Search for the FAH Implementation project . Expand the task list: Define Accounting Configuration for Rapid Implementation . Expand the task list: Define Accounting Rules for Rapid Implementation . Select the task: Manage Journal Entry Rule Set . Click Go to Task . Create a journal entry rule set. Click Create icon. Enter Name . Enter Short Name . Select Event Class . Select Event Type . Select Chart of Accounts . In the Journal Entry region: Select Description Rule you created for the header.. In the Journal Lines region create a credit line. Click Create icon. Select Line Type = Credit . Select Journal Line Rule . Select Account Combination Rule . Select Line Description Rule . In the Journal Lines region create a debit line. Click Create icon. Select Line Type = Debit . Select Journal Line Rule . Select Account Combination Rule . Select Line Description Rule . Select Segment Rule . In the Supporting References region: Click Create icon. Select Supporting Reference . Click Create icon. Select another Supporting Reference . Click Save . From the Actions menu select Activate . Click Yes . Click Save and Close . Click Done .
