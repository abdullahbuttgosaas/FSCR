Create a User-Defined Formula Navigate to the Manage Mapping Sets page. From the Setup and Maintenance work area, click the Implementation Projects button. Search for the FAH Implementation project . Expand the task list: Define Accounting Configuration for Rapid Implementation . Expand the task list: Define Accounting Rules for Rapid Implementation . Select the task: Manage User-Defined formulas . Click Go to Task . Create a formula on the Manage Formulas page. Click Create icon. Enter Name . The Short Name is created but can be updated. Enter Data Type . Enter Event Class . Click Save . In this formula you abbreviate a loan type value. For example, if the loan type is Fixed Rate, then its new value is FR; otherwise the value is AR. In the Expression region: Click Insert Function . Enter Type = Conditional . Click Search . Select IF THEN ELSE Click OK . Place the cursor after the IF, . Click Source . Select Subledger Application . Select Name = Loan Type . Click Search . Select Loan Type . Click OK . Click More . Select Equal To (=) . On the IF line, after the = enter 'Fixed Rate' including the single quotes. On the THEN line, enter 'FR' . On the ELSE line, enter 'AR' . Validate the formula. Click Validate . Click OK on the Information message. Click Save . Activate the formula. Click Actions > Change Status > Activate . Click Save and Close . Create Description Rules In this exercise, you create a header description rule for an accounting event. In this example, we display the loan type, event type, and the customer number at the header level of the journal entry. Navigate to the Manage Description Rules page. Click Go to Task for the Manage Description Rules task. Click Create icon. Enter Name . Enter Short Name . Click Save . In the Rules region, enter the description rule components. Click Create icon. In the Description Details text box enter Loan Type . Click Source . In the Source Search enter Type , Formula . Select the formula you created in the prior step. Click OK . In the Description Details text box, place your cursor at the end of the text and append: Click Source . Search by Name : Accounting Event Type Name . Click OK . In the Description Details text box, place your cursor at the end of the text and append: Click Source . Search by Name : Customer Number . Click OK . Click Save and Close .
