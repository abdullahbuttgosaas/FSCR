Create an Accounting Method Navigate to the Manage Journal Entry Rule Set page. From the Setup and Maintenance work area, click the Implementation Projects button. Search for the FAH Implementation project . Expand the task list: Define Accounting Configuration for Rapid Implementation . Expand the task list: Define Accounting Rules for Rapid Implementation . Select the task: Manage Accounting Methods . Click Go to Task . Create an accounting method. Click Create icon. Enter Name . Enter Short Name . Select Chart of Accounts . In the Journal Entry Rule Set Assignments region: Click Create icon. Enter Event Class . Enter Event Type . Enter Rule Set . Click Save . Activate the rule set assignment. In the Assignments region click Activate . Click Save and Close . Assign the Accounting Method to the Ledger You must assign this accounting method to the ledger you use for accounting and posting journal entries. From the Setup and Maintenance work area, click the Implementation Projects button. Search for the FAH Implementation project . Expand the task list: Define Ledgers . Select the task: Specify Ledger Options . Click Go to Task . On the Specify Ledger Options page, Subledger Accounting region, select the new Accounting Method . Click Save and Close .
