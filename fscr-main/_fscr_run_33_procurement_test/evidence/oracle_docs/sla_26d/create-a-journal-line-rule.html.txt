Navigate to the Manage Journal Line Rules page. From the Setup and Maintenance work area, click the Implementation Projects button. Search for the FAH Implementation project . Expand the task list: Define Accounting Configuration for Rapid Implementation . Expand the task list: Define Accounting Rules for Rapid Implementation . Select the task: Manage Journal Line Rules . Click Go to Task . Create a journal line rule on the Manage Journal Line Rules page: Click Create icon. Enter Name . Enter Short Name . Enter Event Class . Enter Side = Credit . Enter Accounting Class . Click Save and Create Another . Repeat these steps to create another journal line rule, with a Side = Debit . Related Topics Journal Line Rules
