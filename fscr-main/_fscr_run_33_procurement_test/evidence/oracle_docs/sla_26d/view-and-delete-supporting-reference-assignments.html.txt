View Supporting Reference Assignments Select supporting references from the search criteria to view assignments across all subledger applications. Alternatively, select subledger application and event class to view the assignments for a particular subledger application. Delete Supporting Reference Assignments To delete an existing supporting reference assignment, select the required supporting reference and click on the Delete Assignments button.
