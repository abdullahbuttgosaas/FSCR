Create a Mapping Set Navigate to the Manage Mapping Sets page. From the Setup and Maintenance work area, click the Implementation Projects button. Search for the FAH Implementation project . Expand the task list: Define Accounting Configuration for Rapid Implementation . Expand the task list: Define Accounting Rules for Rapid Implementation . Select the task: Manage Mapping Set . Click Go to Task . Create a mapping set on the Manage Mapping Sets page. Click Create icon. Enter Name . Enter Short Name . Enter Output Type . In the Input Source region: Select Actions > Select and Add . Search and select Source . Click OK In the Chart of Accounts region: Click Create icon. Enter Chart of Accounts . Enter Segment . Click Save . In the Mappings region: Click Create icon. Enter Loan Type . Enter Output for Department . Click Create icon. Enter additional Loan Type and Output for Department . Click Save and Close . Click Done . Create Account Rules Create an account rule with a Constant value type on the Manage Account Rule page. Select the Manage Account Rules task. Click Create icon. Enter Name . Enter Short Name . Enter Chart of Accounts . Enter Rule Type . Click Save . In the Rules region: Click Create icon. Enter Value Type = Constant . Enter Chart of Account . Click Save and Create Another . Create an account rule using a segment rule type and a mapping set. Enter Name . Enter Short Name . Enter Chart of Accounts . Enter Rule Type = Segment . Enter Segment . Click Save . In the Rules region: Click Create icon. Enter Value Type = Mapping Set . Enter Value = Mapping Set name . Click Save and Create Another . Create an account rule using an account combination rule type: Click Create icon. Enter Name . Enter Short Name . Enter Chart of Accounts . Enter Rule Type = Account Combination . Click Save . In the Rules region: Click Create icon. Enter Value Type = Constant . Enter Value . Click Save and Close . Click Done . Related Topics How You Define Account Rules
