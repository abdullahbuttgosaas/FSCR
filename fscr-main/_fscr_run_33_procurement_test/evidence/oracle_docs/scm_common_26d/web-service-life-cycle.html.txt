 Previous Next JavaScript must be enabled to correctly display this content Implementing Common Features for SCM Web Service Life Cycle Web Service Life Cycle A web service goes through three phases in a life cycle: Active: A service is active when it's delivered the first time, until it's deprecated. Deprecated: A service is deprecated when it's superseded by a newer version, or if there is a planned obsolescence in a future release. A service in this state is still supported and becomes obsolete in a later release. Note: You must use the active version of the service. If you were previously using a service that has been deprecated, then migrate to the new, active version. Obsolete: A service is obsolete when it's no longer shipped or supported.
