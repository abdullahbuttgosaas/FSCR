How do I define whether the user image, name, or initials display in the global header? Set the User Image Display Enabled (FND_USER_PHOTO_ENABLED) profile option. If you select: Yes, then the user image is displayed in the global header only if the user uploaded a photo. Otherwise, the user's initials are displayed. By default, this profile option is set to Yes. No, then only the user name is displayed in the global header. Related Topics Change Your Photo
