User and Role Synchronization: Explained

User accounts for users of Oracle Fusion Applications are maintained in your Lightweight Directory Access Protocol (LDAP) directory. The LDAP directory also holds information about roles provisioned to users.

During implementation, any existing information about users and their roles must be copied from the LDAP directory to the Oracle Fusion Applications tables. To copy this information, you use the task Run User and Roles Synchronization Process. This task calls the Retrieve Latest LDAP Changes process. You can perform the task Run User and Roles Synchronization Process from either an implementation project or the Setup and Maintenance work area.

Once the Oracle Fusion Applications tables are initialized with this information, it's maintained automatically.
