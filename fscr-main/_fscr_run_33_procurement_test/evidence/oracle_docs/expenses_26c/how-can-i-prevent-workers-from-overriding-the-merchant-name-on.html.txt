How can I prevent workers from overriding the merchant name on credit card transactions? By creating the profile option, EXM_DISABLE_CC_MERCHANT_NAME, and setting the value to Y. When this occurs, the value in the Merchant Name field becomes read-only on the Create Expense Item page for both the web-based and the mobile application. A read-only value in the Merchant Name field prevents employees from changing it, which maintains data integrity.
