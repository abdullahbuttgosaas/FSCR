Can I deploy Oracle Expenses Cloud as a stand-alone application? Yes. You can deploy Oracle Expenses Cloud as a stand-alone application if you perform specific product tasks. In Setup and Maintenance, search and select the Define Ledger Configuration for Rapid Implementation task list and the Define Taxes for Rapid Implementation task list. Additional tasks to perform include: Manage Common Options for Payables and Procurement, Manage Disbursement System Options, Manage Payment Methods, and Manage Payment Process Profiles. You must also set up employees and their assignments in the application.
