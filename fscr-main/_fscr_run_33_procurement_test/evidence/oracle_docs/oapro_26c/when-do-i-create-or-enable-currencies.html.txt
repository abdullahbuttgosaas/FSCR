 Previous Next JavaScript must be enabled to correctly display this content Implementing Procurement When do I create or enable currencies? When do I create or enable currencies? Create or enable any currency for displaying monetary amounts, assigning currency to ledgers, entering transactions, recording balances, or for any reporting purpose. All currencies listed in the International Organization for Standardization (ISO) 4217 standard are supported. The default currency is set to United States Dollar (USD).
