 Previous Next JavaScript must be enabled to correctly display this content Implementing Procurement How can I edit lookups? How can I edit lookups? On any of the Manage Lookups pages, you can edit the existing lookup codes of a lookup type or add new lookup codes. You can edit lookups using the following tasks in the Setup and Maintenance work area: Manage Standard Lookups Manage Common Lookups Manage Set Enabled Lookups Each task contains a predefined set of lookup types that are classified and stored. Open a task to search and edit the required lookup. However, you may not be able to edit a lookup if its configuration level doesn't support editing.
